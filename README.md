# A Day Like Any Other

A short browser game about the hidden environmental cost of an ordinary day.
Five everyday tasks, then a silent reveal of what they add up to over a year.

- Plays in English, Bengali and Chinese
- No build step: open `index.html` in a browser, or serve the folder with any static web server
- Built with HTML, CSS, SVG, GSAP 3.13 and the Web Audio API

Fonts: SolaimanLipi and Ma Shan Zheng, both under the SIL Open Font License (see `fonts/LICENSES.txt`).
